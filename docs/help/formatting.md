# Formatting posts and comments

{{SITE_NAME}} uses Markdown, a way of writing formatting with plain characters. The buttons above the text box add it for you, and "preview" shows how it will look.

## Text

| you type | you get |
|---|---|
| `*italics*` | *italics* |
| `**bold**` | **bold** |
| `~~struck out~~` | ~~struck out~~ |
| `super^script` or `^(several words)` | super^script |
| `` `code` `` | `code` |
| `>!a spoiler!<` | a spoiler, hidden until clicked |
| `:tada:` | an emoji (the 🙂 button lists them) |

## Links

Paste an address and it becomes a link. To link words instead, write `[the words](https://example.com)`. Mentions such as /v/books and /user/name link on their own.

## Paragraphs and lines

Leave a blank line between paragraphs. A single line break is ignored; to break a line without starting a new paragraph, end it with two spaces.

## Lists

    * one item
    * another item

    1. first
    2. second

## Quotes

Start a line with `>` to quote it:

    > what someone else said

## Code blocks

Indent lines by four spaces (or put a line of three backticks before and after them) to show them exactly as typed, in a fixed-width font.

## Tables

    | column | another |
    |---|---|
    | a | b |

## Headings and lines

`# Heading`, `## Smaller heading` and so on make headings; a line of `***` draws a horizontal rule.

## Showing the characters themselves

Put a backslash before a character to stop it formatting: `\*not italic\*`.
