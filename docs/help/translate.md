# Translating {{SITE_NAME}}

{{SITE_NAME}} runs on Tippr, open source software, and its interface can be shown in many languages: choose yours in your [preferences](/prefs/). Languages marked (*) are only partly translated, so some text shows in English.

Translations are part of the software, so they're shared by every site that runs it. To help translate, or to fix a translation, see the project's source code (linked at the bottom of every page) for how translations are made and sent in.

If you spot a mistake but don't want to translate, [tell the admins](/contact#message-the-admins) which page it's on, and what it says and should say.
