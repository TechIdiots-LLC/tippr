# Muting in moderator mail

A vault's moderators can mute a member who sends abusive or repeated messages to their moderator mail. While muted, the member can't message that vault's moderators; everything else is unaffected, including posting in the vault.

A mute lasts 3 days, and moderators can lift it earlier or mute again for longer if it carries on. The member is told when they're muted.

If you were muted and think it was unfair, wait for it to end and then write to the moderators calmly. If moderators are misusing muting, [tell the admins](/contact#moderators).
